# CVPR 投稿个人简介页

本项目包含一个静态 HTML 页面，用于在 CVPR 等学术会议投稿时提供简洁的作者个人简介与补充信息展示。

## 🧭 文件结构

```
CVPR_Submission_Profile.html  # 主页面文件
README_CVPR_Profile.md        # 当前说明文档
assets/                       # 可选：放置头像或样式文件
```

## 🧩 页面概述

该 HTML 页面包括以下主要部分：

1. **基本信息区** — 展示姓名、机构、联系方式与研究标签。
2. **个人简介** — 简述研究方向与学术兴趣。
3. **研究方向与论文列表** — 可填写 3–5 个主要方向与代表性成果。
4. **项目与代码链接** — 指向 GitHub、数据集或复现实验仓库。
5. **技能与工具** — 简要列出常用技术栈。
6. **奖项与资助（可选）** — 用于补充学术荣誉。
7. **右侧信息栏** — 联系方式、下载简历、投稿说明与简介复制按钮。

## 🚀 使用方法

1. 打开 `CVPR_Submission_Profile.html` 文件。
2. 替换以下字段：

   * 姓名、单位、城市与国家
   * 邮箱与个人主页链接
   * 研究方向与代表性论文条目
   * GitHub 项目与代码链接
3. （可选）在 `assets/` 目录中添加头像并在 HTML 中引用：

   ```html
   <img src="assets/photo.jpg" alt="photo" style="width:100%;height:100%;object-fit:cover;border-radius:10px">
   ```
4. 打开浏览器直接查看效果。

## 🧰 自定义样式

可在 `<style>` 区块中调整颜色变量：

```css
:root{
  --bg:#0f1724;
  --card:#0b1220;
  --muted:#9aa7bf;
  --accent:#4f46e5;
}
```

可根据 CVPR 附录或个人主页风格统一配色。

## 📦 导出为 PDF

若需要将该页面提交为补充材料，可使用浏览器打印功能：

```
Ctrl + P → 目标选择 “保存为 PDF” → 边距设为“无” → 勾选背景图形
```
